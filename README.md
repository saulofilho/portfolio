## Como funciona

HTML, CSS e JavaScript puros, sem build e sem dependências.

| Arquivo | O que tem |
| --- | --- |
| `index.html` | Todo o conteúdo da página |
| `styles.css` | Paleta pastel, tipografia (Outfit, DM Sans, IBM Plex Mono), cards e tema claro/escuro |
| `main.js` | Menu mobile e gradiente animado do topo |

Para editar um projeto ou cargo, altere direto o `index.html`.

## Rodar localmente

```bash
python3 -m http.server 4321
```

Depois abra http://localhost:4321.

## Publicação

GitHub Pages, a partir da raiz do branch `main`. Cada push na `main` atualiza o site em cerca de um minuto.
