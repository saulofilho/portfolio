This is where I'll write things down: how a tool came together, what broke on the way, and the bits I'd otherwise forget by next month.

## What to expect

Mostly three kinds of posts:

- **Security tools**, especially for language models and agents.
- **Firmware and music**, from a tiny groovebox that thinks it's a percussion section.
- **Small lessons**, the kind that fit in a paragraph and a code block.

## How this blog works

Each post is a Markdown file in the `posts` folder of the repository. The page reads the folder and renders whatever it finds, so publishing is just a push:

```bash
git add posts/my-new-post.md
git commit -m "New post"
git push
```

That's it. See you in the next one.
